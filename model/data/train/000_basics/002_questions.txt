# The self-loop's questions: a line's text is one input, and each question after the bar is an input
# of its own on the same stack and the same permanent state. The text passes when the state holds the
# shape after the arrow; a question passes when the nodes it brought back from the state are exactly
# its answer. Held out lines use other names, an article the learned lines rarely use, and words for a
# place the learned lines never use.
