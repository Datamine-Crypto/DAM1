# Partial search games: each game states a world the tree holds and the stack does not, then a text
# adds a thing of the same name as one the world holds, or a new place or owner. The stack shows
# only the thing the text added, and the question asks about what the world holds, so the network
# has to take it that the world holds more than the stack shows, look past the thing it just wrote,
# and search the tree for the node that holds the answer. Held out lines use names and things the
# learned lines never use.
