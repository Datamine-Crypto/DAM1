# Partial view games: each game states a world the tree holds and the stack does not, then a text
# tells only part of what happens to it. The stack shows the text; the rest stays in the tree. A
# question asks about the part the text told, the part it never told, or both together, so the
# network has to take it that the thing the text names is the thing the world holds, and search the
# tree for what the stack does not show. Held out lines use names and things the learned lines never
# use.
seed: 90-everyday
seed: 18-qualities
world: ball -> {in} -> box; cup -> {in} -> bag | where is the cup? = bag
then: the ball moves to the shelf. => ball -> {in} -> shelf; not ball -> {in} -> box | where is the ball? = shelf; where is the cup? = bag
world: key -> {in} -> drawer; pen -> {in} -> cup | where is the key? = drawer
