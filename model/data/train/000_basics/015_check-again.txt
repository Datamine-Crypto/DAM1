# Check again games: a text tells the network some details, a question asks whether it remembers
# one, and the world then changes with nothing on the stack, the way things move while nobody
# tells. The next question asks again, so the network has to search the tree once more instead of
# trusting the answer still on its stack: what it found before may be gone, and what it found nothing
# of may be there now. Held out lines use names and things the learned lines never use.
seed: 90-everyday
seed: 18-qualities
john has a coat. john has a scarf. => john -> {has} -> coat; john -> {has} -> scarf | do you remember if john has a hat? = no; does john have a coat? = yes
then: world: john -> {has} -> hat | check again, does john have a hat? = yes; does john have a coat? = yes
ann has a ball. => ann -> {has} -> ball | does ann have a ball? = yes; does ann have a kite? = no
then: world: ann -> {has} -> kite | check again, does ann have a kite? = yes; what does ann have? = ball, kite
the cat is in the garden. => cat -> {in} -> garden | where is the cat? = garden; is the cat in the house? = no
then: world: cat -> {in} -> house; not cat -> {in} -> garden | check again, where is the cat? = house; is the cat in the garden? = no
