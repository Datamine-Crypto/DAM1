# Trick games: questions built to mislead. A question names an owner who has something else, a
# thing only the question names, a colour the thing does not have, or a name one letter away from
# the right one; a silent change touches someone else, or is undone by the next; a count is asked of
# the wrong person. The answer is what the tree holds, never the word the question dangles, so the
# network has to search and check instead of echoing. Held out lines use names and things the
# learned lines never use.

seed: 18-qualities
john has a hat. ann has a coat. => john -> {has} -> hat; ann -> {has} -> coat | does ann have a hat? = no; does john have a coat? = no; who has the hat? = john; who has the coat? = ann
tom has a red hat. => tom -> {has} -> hat -> {red} | who has the blue hat? = {nothing}; who has the red hat? = tom; is the hat blue? = no

then: world: sam -> {has} -> cat | check again, does kim have a cat? = no; who has the cat? = sam; does kim have a dog? = yes
