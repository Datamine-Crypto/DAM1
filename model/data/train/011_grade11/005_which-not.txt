# Which is not: a denied join is kept, so a question that denies the same join finds the thing
# the text denied. Only what the text denied is an answer, not everything never said to join.
# The word not marks the pointer that follows, as it does in a statement. The traced lines keep
# their text and take many questions; each scene tells joins and denied joins of different kinds,
# then asks what is and is not each kind, yes or no, and a denial never told, which is nothing.
