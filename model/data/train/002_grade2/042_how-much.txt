# A word of degree, very, really or totally, is kept on the quality it strengthens, so the tree
# holds how hot the soup is and not only that it is hot. Held out lines use things and qualities
# the learned lines never use.
the soup is very hot. => soup -> {is} -> {temperature} -> hot -> {degree} -> very | is the soup hot? = yes
my bookshelf is a mess. it is totally disorganized. => user -> bookshelf -> {is} -> disorganized -> {degree} -> totally | what is my bookshelf? = mess, disorganized
tom is really tall. => tom -> {is} -> {size} -> tall -> {degree} -> really | who is tall? = tom
anna has a very big dog. => anna -> dog -> {is} -> {size} -> big -> {degree} -> very | what does anna have? = dog
the box is quite heavy. => box -> {is} -> heavy -> {degree} -> quite | is the box heavy? = yes
the water is extremely cold. => water -> {is} -> {temperature} -> cold -> {degree} -> extremely | is the water cold? = yes
mia is super happy. => mia -> {is} -> {feeling} -> happy -> {degree} -> super | how does mia feel? = happy
