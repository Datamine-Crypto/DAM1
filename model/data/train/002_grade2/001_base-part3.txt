# A comparative is a named relation: "bigger" names it, "than" does nothing, "bag" completes it,
# and both ends are kept. The trained readers of the time read it as a quality instead ("box is bigger") and ends the
# sentence at "than", so the thing compared against is thrown away. Two rows are wrong, and the
# step between the readings, moving "than" alone, changes no statement, so only a trace can pay
# for it (measured in a_comparison_can_keep_both_ends_now_that_a_word_can_name_a_relation).
#
# The trace asserts the STATE and not the route: a "label" pointer waiting after "bigger", and
# nothing about which behavior left it there. "bigger" has a second job in "a bigger box is in
# the house", where it is a quality. The hand-made Label program does both, the way Quality does:
# with an "is" pointer waiting the word names the relation, otherwise it is a quality of the next
# name. The scene with "a bigger box is in the house" asserts the other state (no pointer after
# "bigger") so one row serves both.
#
# Checked satisfiable by hand before it was written here: the (Label, Skip) reading scores 1.0 on
# trace and statement, and the (Quality, Settle) reading the readers of the time took falls short of it.
