# Having, in every plain form: has, have, have got, got, owns, belongs to, and a name with an
# apostrophe (tom's car). Each is written as the one {has} relation, so the network learns that the
# forms are one concept. Each scene tells a few owners, some with several things and some things
# of one kind under several owners, then asks from every side: who has, who owns, whose, what does
# X have, what does X own, does X have Y (yes and no), how many things does X have, and a thing no
# one has. A list answer names the things in the order they were told.

seed: 18-qualities
