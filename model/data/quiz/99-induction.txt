# Induction, as the bAbI stories say it: things of one kind share what one of them is. Bernhard is a
# lion and bernhard is white, brian is a lion, so asked what color brian is, the answer is what the
# other lions are; the class word color was never named, so it asks nothing of its own.
# A bAbI induction story is already several statements, so each scene is one story of three to five
# statements, asked the color of every one of its things, each kind, yes and no, and the color of a
# name the story never told, which is nothing.
bernhard is a lion. bernhard is white. brian is a lion. => bernhard is lion; bernhard is white; brian is lion | what color is brian? = white; what color is bernhard? = white; what is brian? = lion; is bernhard a lion? = yes; is brian a lion? = yes; is brian a swan? = no; is brian white? = yes; is bernhard gray? = no; is brian gray? = no; what color is lily? = nothing
