# The quiz: a text, then "=>", then the space it should build, then (optional) "|" and
# questions with their answers: "question = answer; question = answer".
# Statements: "X in Y" (X is inside Y), "X is Y" (X joined the group Y), "X owns Y", "X: fact".
# Separate with ";".
# Answers: names ("green"; "bike, car" when more than one), "yes", "no", "nothing", or a number
# written in digits.
# Every line starts from an empty space. Only the permanent space counts: what the reader kept
# when a sentence settled. Questions are asked of that space. No word has a meaning in the code: the
# reader learns which behaviors each word promotes from these lines.
# Most lines are scenes: two to five statements, then many questions about them. The questions
# ask each fact in several wordings (where is X, what is in Y, is X in Y), ask about a thing the
# scene does not name (nothing, no), and combine facts where the concept allows. Things in one
# scene have distinct names, unless the concept is about two of the same kind. Simple scenes come
# first. Turn lines stay one statement and one question, since a turn draws one answer.
# Lines that start with "test:" are held out: the reader never learns from them; they show if
# what was learned works on new sentences. Test scenes use new names and things in the shapes
# the learned scenes teach.
# The shape of the numbers facts: the digits put their number on the stack, "=" applies nothing,
# and the word takes the number. Read before the facts are seeded, so the word's value comes only
# from the digits; the facts file 14-numbers.txt is written in this shape and seeded for the rest.
# These scenes only state, since the facts file they teach only states.

# A comparative is a named relation: "bigger" names it, "than" does nothing, "bag" completes it,
# and both ends are kept. The trained readers of the time read it as a quality instead ("box is bigger") and ends the
# sentence at "than", so the thing compared against is thrown away. Two rows are wrong, and the
# step between the readings, moving "than" alone, changes no statement, so only a trace can pay
# for it (measured in a_comparison_can_keep_both_ends_now_that_a_word_can_name_a_relation).
#
# The trace asserts the STATE and not the route: a "label" pointer waiting after "bigger", and
# nothing about which behavior left it there. "bigger" has a second job in "a bigger box is in
# the house", where it is a quality. The hand-made Label program does both, the way Quality does:
# with an "is" pointer waiting the word names the relation, otherwise it is a quality of the next
# name. The scene with "a bigger box is in the house" asserts the other state (no pointer after
# "bigger") so one row serves both.

# How the world is, not just how sentences are. Every form here was measured against the readers of
# the time before being written: taxonomy, containment and part-of all read correctly with words no reader
# has ever seen, because the default row guesses "name" for an unknown word (97% to 100% in every
# reader). Three forms are deliberately absent. Causal and temporal facts keep nothing ("ice melts
# because it is warm." builds an empty space), counted facts are mangled ("a week has seven days."
# becomes "seven in week" and loses the days), and "what does X have?" retrieved nothing when these
# were first written, so the questions also ask "what is in X?" and "what has Y?".
