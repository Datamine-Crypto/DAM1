# Durations: something that starts at one hour and ends at a later one lasts the difference, kept as a
# start and an end from the thing to each hour, and asked back with how long.
# Each scene tells when two things start and end, then asks how long each lasts, when each starts and
# ends, which is longer or starts first, how much longer, both together, and a thing the scene never
# told.
